## Libraries and Frameworks
This project would not be possible without the following incredible open-source projects:

*   **PySide6 (Qt for Python):** For the rich graphical user interface.
*   **Hamlib (rigctld):** For cross-platform CAT radio control.
*   **ONNX Runtime:** For accelerating the AI neural network inference.
*   **DeepCW:** For the state-of-the-art Morse Code decoding neural network model. (DeepCW Model Architecture is utilized under its open-source license).
*   **NumPy & SciPy:** For digital signal processing and real-time audio waterfall generation.
*   **Sounddevice & Soundfile:** For low-latency cross-platform audio capturing and playback.
